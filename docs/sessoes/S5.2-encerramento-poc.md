## 1. O que era para fazer

Fechar a POC de catálogo dinâmico. Depois da correção do parser OQ3D (S5.1), o banco
e o storage ainda tinham geometria do parser antigo. Era preciso zerar tudo, recarregar
do zero e conferir que geometria, miniaturas e páginas estão corretas.

## 2. O que foi feito

**Limpeza.** Banco Atlas `bilds-bim-3d` zerado (17 documentos em 4 coleções) e
`www/storage/bim` esvaziado (45 MB, 39 arquivos), preservando os quatro diretórios
(`geo`, `thumbs`, `geometrias`, `logos`). Backup dos documentos antes de apagar.
Servidores derrubados e resubidos desacoplados (`setsid nohup`), api em 4000 e web
em 3000.

**Carga limpa.** As duas bibliotecas foram importadas pela própria interface, já com o
parser corrigido:

| Catálogo | Slug | Produtos | Layout | importId |
|---|---|---|---|---|
| Bomba de Combate a Incêncio | `bomba-de-combate-a-incencio` | 13 | `series-rows` | `d5a4acb5` |
| PVC Esgoto Silentium | `pvc-esgoto-silentium` | 856 | `catalog-grid` | `28826de9` |

Empresa: Dancor, `/dancor`, id `5fad3dc6-91b8-4c85-af4e-419aae415ae0`.

## 3. O que foi verificado — e como

**Integridade dos 869 produtos.** Consulta ao Mongo cruzando cada `geoKey`/`thumbKey`
com o arquivo em disco:

```
produtos: 869
  sem geoKey   : 0    arquivo de geometria faltando: 0
  sem thumbKey : 0    arquivo de thumb faltando   : 0
```

**A geometria é a do parser corrigido.** É o teste decisivo — a contagem de triângulos
separa as duas versões sem ambiguidade:

```
www/storage/bim/geo/d5a4acb5-.../2cv-t-220-380v-inc-flg-ir3.json
  vertices  : 16.488     (dedup de 82.275 → 80%)
  triangulos: 27.425     ← parser corrigido (o antigo dava 20.452)
```

27.425 é exatamente o total que o IFC da CAM-W21 2CV declara, conferido em S5.1.

**Miniaturas.** `GET /thumbs/:productId` devolve `image/webp`, 5.638 bytes. A imagem
foi inspecionada: anel de parafusos completo no flange, nada solto no ar — idêntica à
que o pipeline estático produz.

**Páginas.** API e web respondem 200 nos dois catálogos:

```
/catalogos/dancor/bomba-de-combate-a-incencio   [200]   /dancor/bomba-de-combate-a-incencio   [200]
/catalogos/dancor/pvc-esgoto-silentium          [200]   /dancor/pvc-esgoto-silentium          [200]
```

**Login.** `POST /auth/login` com o `SEED_USER` devolve token; `/auth/me` → 200.

## 4. Decisões tomadas

- **Backup do banco antes de apagar**, mesmo sendo dado de teste: 17 documentos, 44 KB,
  custo desprezível. O storage não foi copiado — é regenerável a partir de `input/`.
- **Diretórios do storage preservados vazios** em vez de apagar `bim/` inteiro: o
  `DiskGeometryStore` resolve o caminho no construtor e não é ele quem cria a árvore.
- **Servidores resubidos com `setsid nohup`**, não como processo filho da sessão, para
  sobreviverem ao fim dela. Logs em arquivo.

## 6. Surpresas — onde a documentação estava errada

1. **O `CLAUDE.md` dizia que o catálogo Amanco "não está nesta máquina"** e citava
   `importId f7097e2e`. Desatualizado: a Amanco está carregada, com 856 produtos e
   importId novo. Corrigido.
2. **Os importIds documentados (`59c32b93`) não existiam mais.** Substituídos pelos
   atuais, com o aviso de que mudam a cada reimportação já reforçado.
3. **O campo do produto é `geoKey`, não `geometryKey`.** Uma primeira consulta de
   verificação usou o nome errado e acusou "869 produtos sem geometria", que era falso
   alarme. Os campos reais são: `_id, catalogId, importId, id, nome, serie, specs,
   curva, conexoes, potencia, geoKey, thumbKey`.
4. **O login não depende do banco.** `auth.controller.ts` compara direto com
   `SEED_USER`/`SEED_PASSWORD` do `.env` — apagar `companies` não impede o acesso.
   Vale saber antes de limpar o banco achando que vai se trancar para fora.

Armadilhas concretas desta sessão:

- O banco é um **Atlas M0 remoto**, não local. Limpar é irreversível sem backup.
- `www/storage/bim` e o banco andam juntos: zerar um sem o outro deixa `geoKey`
  apontando para arquivo que não existe (ou órfãos de 363 MB em disco).
- Os servidores estavam rodando de uma sessão anterior. **Confira as portas 3000 e
  4000 antes de subir qualquer coisa** — subir em cima dá porta ocupada.
