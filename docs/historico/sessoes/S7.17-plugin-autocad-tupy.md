## 1. O que era para fazer

Pedido do usuário, palavra por palavra na intenção: localizar o plugin de AutoCAD da Tupy
(sistema Catallog) recém-instalado no Windows, **estudar como decodificar "a biblioteca DLL" em
um `.aq`** para o AltoQi Builder usando o que o projeto sabe de IFC/`.aq`/STEP/CAD, provar a
viabilidade com testes, e então **acrescentar um botão na página inicial** para importar um
plugin de AutoCAD como catálogo do bilds-bim-3d — editável e exportável para `.aq` como os outros.
Depois, com o estudo em mãos, ele restringiu: baixar só os **18 grupos da categoria TupyGrooved**
em `conexoes.tupy.com.br`, "inclusive rvts", com os dados reais dele no formulário de download,
guardar tudo numa pasta do projeto e ir até o `.aq`.

Pronto quando: `.aq` gerado das peças Tupy e relido pelos leitores do projeto; botão na home que
faz o mesmo pelo serviço; testes; registro.

## 2. O que foi feito

**Estudo** (`eng-reversa/tupy/estudo/01-plugin-tupycad-e-catalogo-web.md`): a DLL (35 KB, .NET) não tem
geometria — abre `https://tupycad.catallog.digital` numa paleta e expõe `InsertBlockFromURL`/
`RequestDownload`/`GetPluginVersion` para a página; o catálogo web tem API REST pública
(`/api/marketplace/v1|v2/…`), um **IGES** (SolidWorks, faces soltas) por produto, um **`.rfa`**
Revit por família, DXF 2D; o download passa por `POST /api/crm/v1/form/` com nome/e-mail/
telefone/empresa/cargo e devolve a URL. Termos de Uso lidos e registrados (§2.2 do estudo).

**Pipeline** (`www/apps/ingestao/pipeline/`):
- `step_to_geo.py` lê **IGES** (`.igs/.iges`): `IGESCAFControl_Reader`; sem sólido, `BRepBuilderAPI_Sewing` (0,01 mm) → `MakeSolid` + `ShapeFix_Solid` → **volume assinado negativo → `Reverse()`**; cor por face preservada via `Sewing.Modified`; saída ganha `formato`, `volume_cm3`, `costurado`, `arestas_livres`. STEP inalterado (Dancor 2831A09: 7.506 △, como antes).
- `catallog.py` (novo): `inspecionar <dll>` (strings UTF-16 → host, plugin, versão; com rede: título e categorias com nº de grupos) e `importar` (plano por grupo → formulário → download com manifesto idempotente → IGES → `geo/<código>.json` → catálogo no **mesmo JSON do `catalogo_de_aq.py`**; specs: Código, tamanhos, atributos, tabela Dimensionais com cabeçalho `colspan`/`rowspan`, Material/Normas, Tipos Revit, Fonte 3D, URL, Plugin).
- `rfa_partatom.py` (novo): `PartAtom`/`BasicFileInfo`/preview de um `.rfa` sem o Revit (`olefile`, opcional).

**Serviço de ingestão:** tipo de import `plugin` (`@bim/dominio`), `ImportarPluginDto`, `POST /importacoes/plugin-autocad/inspecionar` e `POST /importacoes/plugin-autocad`; `PipelineService.inspecionarPlugin`/`catalogoDePlugin` (lead em JSON temporário 0600, apagado); `ImportacoesService.processarCatalogo` — o caminho comum ao `.aq` e ao plugin (o `processarAq` virou um chamador); downloads em `storage/bim/catallog/<importId>/`, removidos com o import (`remocao.ts`) e no `falhou`; `UPLOAD_TEMPORARIO` reconhece `plugin-<uuid>.dll`; `.igs` aceito como peça CAD (`formatoDe` → 'iges', spec Formato/Volume/Arestas livres).

**Web:** botão **Importar plugin do AutoCAD** na home → `/importar/plugin` (DLL → inspecionar → empresa, categoria, host, peças por grupo, deflexão, formulário de lead lembrado em `localStorage` → 202 → `/importar` acompanha); `.igs` em "Importar peça" e `/cad`.

**Estudo/ferramentas** (`eng-reversa/tupy/`): `tools/tupy_baixar.py`, `tools/tupy_catalogo.py` (CLIs finas sobre `catallog.py`), `dados/` (JSONs públicos; `lead.local.json` gitignored), `downloads/` e `saida/` gitignored. `.gitignore` atualizado.

**Testes:** `tests/test_step_to_geo.py` (IGES de uma caixa escrita pelo OCC: costurado, volume, normais para fora, CLI; STEP da mesma caixa não costura; IGES da Tupy quando presentes), `tests/test_catallog.py` (DLL sintética e real, `validar_lead`, `specs_do_produto` com a tabela de duas linhas, `catalogo_de_downloads` com um IGES real, manifesto real), `ImportarPluginDto` no harness `validacao.cts` + `test_www_validacao.py`.

## 4. Decisões tomadas

- **Parar antes de baixar e perguntar.** Os Termos de Uso do catálogo proíbem redistribuição e obras derivadas, e o download é um formulário de lead. A sessão apresentou o achado e quatro opções; o usuário autorizou 18 grupos com os dados reais dele, como empresa parceira em estudo. O `catallog.py` e a página web deixam isso explícito: os dados são de quem importa, vão só ao catálogo do fabricante, não são persistidos.
- **Um IGES por grupo (família) por padrão.** "18 arquivos" na fala do usuário eram os 18 cards de família; cada família tem N tamanhos (193 produtos em TupyGrooved). `igsPorGrupo` (1 / N / -1 todos / 0) deixa a escolha; o estudo baixou 1.
- **IGES entra no `step_to_geo.py`, não num módulo novo** — o contrato de saída é o mesmo e a costura serve também para um STEP que venha só com cascas.
- **Orientação pelo volume assinado**, não só `ShapeFix_Solid`: o TAMPÃO (10 arestas livres) provou que o fix não inverte casca aberta.
- **O plugin vira o MESMO JSON do `catalogo_de_aq.py`** e passa pelo mesmo `processarCatalogo` — nenhum caminho novo de publicação; o `.aq` reaproveita `catalogo_to_aq.py` sem mudança.
- **Downloads ficam** em `storage/bim/catallog/<importId>/` (são a fonte; o usuário pediu para guardar) e saem com o import.
- **`.rfa` não é convertido em geometria** — `Partitions/30` é proprietário; o que se aproveita é o `PartAtom` (tipos DN32…DN200) como spec. Dito ao usuário.
- Ferramentas do estudo são CLIs finas sobre o pipeline (uma implementação, sem duplicar API/formulário).

## 5. O que NÃO foi feito, e por quê

- **Abrir o `.aq` no AltoQi Builder** — só o usuário pode; é o próximo passo de aceitação (na S7.16 a Amanco foi aceita).
- Os 193 tamanhos de TupyGrooved e as outras 5 categorias — fora do escopo autorizado (≈930 IGES, ≈2 GB no catálogo inteiro).
- DXF 2D → simbologia 2D do `.aq` — fora do escopo; os DXF são vistas para o AutoCAD.
- `/api/marketplace/v1/resources/…` por uuid, `/download/` etc. — 404; não existem (é por slug e pelo formulário).
- Uma DLL de outro fabricante Catallog não foi testada — `inspecionar_dll` escolhe o host por `catallog|collabo` no domínio, senão o primeiro.
- O catálogo importado ficou sob a empresa `amanco` (a primeira cadastrada) — só um teste; criar a empresa Tupy e reimportar é um clique.
- `next build` não foi rodado (derruba o `next dev` — armadilha da S7.16); só `tsc --noEmit`.
