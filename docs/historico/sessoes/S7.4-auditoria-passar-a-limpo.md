## 4. Decisões tomadas

- **`autoescape=True` em vez de `| e` pontual.** Escapar só o chip deixaria título, meta
  description e fabricante expostos ao mesmo problema. Sob autoescape o `tojson` escapa
  `<`, `>`, `&` como `\uXXXX`, o que também protege o `<script>` de um nome com
  `</script>`. O fallback sem Jinja2 (I7) ficou como estava — não é crítico.
- **Handler lê o DOM (`this.dataset.filter`)** em vez de repetir o texto numa string JS:
  elimina a segunda injeção sem depender de filtro de escape para JS.
- **`FileNotFoundError` sobe em `peek_metadata`, o resto continua engolido.** Caminho
  errado é erro do operador; "existe mas não é `.aq`" continua sendo decisão do caller
  (o `build.py` já trata `fabricante` vazio).
- **Mapear as curvas campo a campo** em vez de `as unknown as`: o cast escondia que as
  colunas SQL e a interface podiam divergir.
- **Não commitar até o usuário pedir**; ele pediu "comitar local" e o push ficou de fora
  de propósito (C5 é decisão dele).
