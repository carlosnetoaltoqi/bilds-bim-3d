# Histórico

Registro, não guia: nada aqui orienta o trabalho atual (`docs/arquitetura.md` e `docs/conhecimento/`
orientam). Os nomes de fabricantes e os caminhos da época ficam como estavam — é história (ADR-016).

- `sessoes/` — um registro por sessão de trabalho e o índice cronológico (`README.md`); o mais recente é o que `CLAUDE.md` aponta.
- `estudos/` — os estudos que geraram conhecimento e para onde ele foi promovido (`README.md` mapeia).
- `planos/` — planos, auditoria e inventários superados (a arquitetura anterior em três apps; o plano da integração; a POC dinâmica).
- `preview-estatico/` — o gerador de preview HTML com Jinja2 (saiu do produto em 2026-09-06, ADR-017).
